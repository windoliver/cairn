# Bench Scorecards

Release scorecards are generated by the manual `bench / world-v1` workflow and
published alongside tagged releases.

The public CLI entrypoint is:

```bash
cairn bench scorecard \
  --fixture fixtures/v0/brainbench-world-v1 \
  --out-dir target/bench-full --skip-openai
```

The release workflow runs the same harness directly:

```bash
cargo run --release -p cairn-bench --locked -- scorecard \
  --fixture fixtures/v0/brainbench-world-v1 \
  --out-dir target/bench-full --skip-openai
```

When `OPENAI_API_KEY` is available, the same scorecard is built with the
`openai` feature and includes the `hybrid-openai-rrf` column.

Default scorecard runs do not fetch local embedding models. If
`BGE-small-en-v1.5` is not already cached under `.cairn/models`, BGE-backed
columns are reported as skipped. Set `BENCH_FETCH_MODELS=1` only for jobs that
are allowed to download the model.

Each release scorecard should commit or attach:

- `report.md` - macro-averaged P@5, R@5, MRR, and nDCG@5.
- `per-query.jsonl` - one row per `(adapter, query)` with ranked hits and
  per-query metrics. Rows validate against
  `crates/cairn-bench/schemas/per-query.schema.json`.

The committed BrainBench fixture lives at `fixtures/v0/brainbench-world-v1/`.
It is deterministic and the offline columns do not require external API keys.
