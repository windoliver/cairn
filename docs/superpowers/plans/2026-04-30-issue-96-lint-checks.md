# `lint` Health Checks Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement issue #96 — wire `cairn lint` to perform six read-only health checks plus one deferred-info placeholder, returning structured findings through a new IDL surface.

**Architecture:** Pure check functions in `cairn-core::verbs::lint` operating over a `LintInputs` snapshot the CLI builds from adapters. IDL extension regenerates wire types/schemas. CLI handler wires the live SQLite store, runs checks, writes optional `.cairn/lint-report.md`. No new contracts beyond a counts-only `index_stats` method on `MemoryStore`.

**Tech Stack:** Rust 1.95.0, edition 2024, tokio, rstest, proptest, insta, rusqlite, clap 4.5. Codegen via `cairn-codegen`.

**Spec:** `docs/superpowers/specs/2026-04-30-lint-checks-design.md`. Read it first; this plan implements PR-1 scope only.

```rust
use cairn_core::contract::memory_store::IndexStats;

/// Counts active records and `records_fts` rows in a single read. Both
/// queries run against the same connection but in two SELECTs; brief §5.6
/// allows transient skew on derived indexes — the lint check tolerates
/// it (one-off transient findings re-run cleanly).
pub(crate) async fn index_stats(
    conn: &deadpool_sqlite::Object,
) -> Result<IndexStats, super::super::StoreError> {
    let conn = conn.clone();
    tokio::task::spawn_blocking(move || -> rusqlite::Result<IndexStats> {
        let conn = conn.lock().expect("sqlite conn lock poisoned: should never fail");
        let records_active: u64 = conn.query_row(
            "SELECT COUNT(*) FROM records WHERE active = 1 AND tombstoned = 0",
            [],
            |row| row.get(0),
        )?;
        let fts5_rows: u64 = conn.query_row(
            "SELECT COUNT(*) FROM records_fts",
            [],
            |row| row.get(0),
        )?;
        Ok(IndexStats { records_active, fts5_rows })
    })
    .await
    .expect("spawn_blocking join: invariant: tokio runtime not shutting down")
    .map_err(super::super::StoreError::from)
}
```

If the connection wrapper in this crate is not `deadpool_sqlite::Object`, match the existing pattern from any other read fn in `read.rs` (e.g. how `list_active_stored` acquires its connection). The shape of the body — three queries inside `spawn_blocking`, one per count — is what matters; the `conn` plumbing should mirror the crate's existing convention.

```rust
//!
//! Spec: `docs/superpowers/specs/2026-04-30-lint-checks-design.md`.
//! Issue: <https://github.com/windoliver/cairn/issues/96>.

use crate::config::CairnConfig;
use crate::contract::memory_store::{IndexStats, StoredRecord};
use crate::generated::verbs::lint::{
    LintData, LintDataFindings, LintDataFindingsKind, LintDataFindingsSeverity,
    LintDataFindingsTarget, LintDataSummary, LintDataSummaryBySeverity,
};
use std::collections::BTreeMap;

pub mod checks;

/// One linted record + the per-row consent_model gate from the records
/// table. PR-1 always carries `LegacyEvent` because the migration that
/// adds the column is part of #253; lint behavior in PR-1 is independent
/// of this value (the §6.5 deferred-info finding is emitted unconditionally).
#[derive(Debug, Clone)]
pub struct LintRecord {
    pub stored: StoredRecord,
    pub consent_model: ConsentModel,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
#[non_exhaustive]
pub enum ConsentModel {
    LegacyEvent,
    ReceiptTimeline,
}

/// Snapshot the check engine operates over. Pure inputs; no I/O.
#[derive(Debug)]
pub struct LintInputs<'a> {
    pub records: &'a [LintRecord],
    pub config: &'a CairnConfig,
    pub index_stats: IndexStats,
    /// Current contract version reported by the runtime — drives §6.4.
    /// Major.minor pair; patch is irrelevant for schema lag.
    pub schema_version: SchemaVersion,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct SchemaVersion {
    pub major: u32,
    pub minor: u32,
}

impl SchemaVersion {
    /// Minor-version delta record_minor → current. Negative if the record
    /// is somehow ahead (treat as zero — that's a different defect class).
    pub fn minors_behind(self, record: SchemaVersion) -> u32 {
        if record.major != self.major {
            // Major mismatch is its own error class; report as ≥2 so the
            // schema check classifies it as error.
            return u32::MAX;
        }
        self.minor.saturating_sub(record.minor)
    }
}

/// Run every check, aggregate findings, return the canonical `LintData`.
#[must_use]
pub fn run_checks(inputs: &LintInputs<'_>) -> LintData {
    let mut findings: Vec<LintDataFindings> = Vec::new();
    findings.extend(checks::malformed::run(inputs));
    findings.extend(checks::actor_chain::run(inputs));
    findings.extend(checks::provenance::run(inputs));
    findings.extend(checks::schema::run(inputs));
    findings.extend(checks::hot_memory::run(inputs));
    findings.extend(checks::index_drift::run(inputs));
    findings.extend(checks::consent_deferred::run(inputs));
    let summary = summarize(&findings);
    LintData {
        findings,
        summary,
        report_path: None,
    }
}

fn summarize(findings: &[LintDataFindings]) -> LintDataSummary {
    let mut by_severity = LintDataSummaryBySeverity { error: 0, warning: 0, info: 0 };
    let mut by_kind: BTreeMap<String, u64> = BTreeMap::new();
    for f in findings {
        match f.severity {
            LintDataFindingsSeverity::Error   => by_severity.error += 1,
            LintDataFindingsSeverity::Warning => by_severity.warning += 1,
            LintDataFindingsSeverity::Info    => by_severity.info += 1,
        }
        *by_kind.entry(kind_key(f.kind)).or_default() += 1;
    }
    LintDataSummary {
        total: findings.len() as u64,
        by_severity,
        by_kind,
    }
}

fn kind_key(k: LintDataFindingsKind) -> String {
    use LintDataFindingsKind::*;
    match k {
```

```rust
//! `LintData → markdown` projector for `cairn lint --write-report`.

use crate::generated::verbs::lint::{
    LintData, LintDataFindings, LintDataFindingsSeverity,
};

#[must_use]
pub fn render(data: &LintData) -> String {
    let mut out = String::new();
    out.push_str("# Lint report\n\n");
    out.push_str(&format!("- total: {}\n", data.summary.total));
    out.push_str(&format!("- error: {}\n", data.summary.by_severity.error));
    out.push_str(&format!("- warning: {}\n", data.summary.by_severity.warning));
    out.push_str(&format!("- info: {}\n\n", data.summary.by_severity.info));
    if data.findings.is_empty() {
        out.push_str("_no findings_\n");
        return out;
    }
    out.push_str("## findings\n\n");
    for f in &data.findings {
        let sev = match f.severity {
            LintDataFindingsSeverity::Error   => "ERROR",
            LintDataFindingsSeverity::Warning => "WARN ",
            LintDataFindingsSeverity::Info    => "INFO ",
        };
        out.push_str(&format!("- **{sev}** [{:?}] {}", f.kind, f.message));
        if let Some(fix) = &f.suggested_fix {
            out.push_str(&format!("\n  - fix: {fix}"));
        }
        if let Some(t) = &f.target {
            if let Some(rid) = &t.record_id {
                out.push_str(&format!("\n  - record: {rid}"));
            } else if let Some(p) = &t.path {
                out.push_str(&format!("\n  - path: {p}"));
            }
        }
        if let Some(issue) = f.tracking_issue {
            out.push_str(&format!("\n  - tracking: #{issue}"));
        }
        out.push('\n');
    }
    out
}
```
