# Issue #254 — `lint --fix-markdown` + WAL/lock-table integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `cairn lint` emit projection-drift findings in read-only mode and `cairn lint --fix-markdown` rebuild the `raw/` markdown projection from DB under a §5.6 lock-table lock with WAL-tracked op-kind, all without OS advisory locks.

**Architecture:** Read-only `lint` runs an async projection-drift check (DB row vs on-disk markdown) and emits `ProjectionDrift`/`ProjectionMissing` findings (warning severity, never mutates). `--fix-markdown` (and a new `--fix` umbrella) acquires an exclusive lock at `(scope_kind='lint_repair', scope_key=vault_id)` via a new lock-table API in `cairn-store-sqlite`, opens a WAL `lint_repair` op (ISSUED → PREPARED → COMMITTED), replays the existing `MarkdownProjector` over every active row writing only on drift/miss, and atomically releases the lock + commits the WAL op. Concurrent attempts fail closed with `lint.fix_in_progress` → exit 69. Crash mid-run leaves DB unchanged; the next run reclaims the orphaned lock via TTL and re-fixes.

**Tech Stack:** Rust 2024 / tokio / sqlx (existing), thiserror, anyhow (CLI only), insta, rstest, proptest, tempfile.

**Brief sections touched:** §3 (vault projection authority), §4 (`MemoryStore` contract — extending lock surface), §5.6 (WAL state machine + lock table), §8.0 (lint verb), §15 (lint regression gates).

**Invariants touched:** #5 (WAL + 2PC for every mutation — `lint_repair` joins the FSM), #6 (fail-closed on capability — `lint.fix_in_progress`), #8 (no `unwrap`/`expect` in core), #10 (vault projection authority).

```rust
/// Outcome of comparing a DB-derived projection against an on-disk file.
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum ProjectionStatus {
    /// On-disk content matches the canonical projection (after line-ending normalization).
    Match,
    /// File exists but disagrees with the projection.
    Drift {
        /// blake3 hex of the canonical projection body.
        expected_body_hash: String,
        /// blake3 hex of the on-disk body.
        actual_body_hash: String,
    },
    /// File is absent or unreadable.
    Missing {
        /// blake3 hex of the canonical projection body.
        expected_body_hash: String,
    },
}

/// Hash a projection body deterministically.
///
/// Normalizes CRLF → LF and ensures a single trailing newline before hashing,
/// so that line-ending differences between platforms or editors do not register
/// as drift. Returns lowercase hex of the blake3 digest.
#[must_use]
pub fn body_hash(s: &str) -> String {
    let normalized = normalize_for_hash(s);
    blake3::hash(normalized.as_bytes()).to_hex().to_string()
}

fn normalize_for_hash(s: &str) -> String {
    let lf = s.replace("\r\n", "\n");
    if lf.ends_with('\n') { lf } else { format!("{lf}\n") }
}

/// Compare a canonical projection (`expected`) against an optional on-disk
/// reading (`actual`). Pure — no I/O.
#[must_use]
pub fn compare_projection(expected: &str, actual: Option<&str>) -> ProjectionStatus {
    let expected_hash = body_hash(expected);
    match actual {
        None => ProjectionStatus::Missing { expected_body_hash: expected_hash },
        Some(disk) => {
            let actual_hash = body_hash(disk);
            if expected_hash == actual_hash {
                ProjectionStatus::Match
            } else {
                ProjectionStatus::Drift {
                    expected_body_hash: expected_hash,
                    actual_body_hash: actual_hash,
                }
            }
        }
    }
}
```

```rust
//! Lock-table acquisition for §5.6.
//!
//! All locks live as rows in `.cairn/cairn.db`. SQLite write serialization
//! plus the schema's triggers (migration 0004) provide the mutual-exclusion
//! guarantee. **No OS advisory locks** (`flock`, `fcntl(F_SETLK)`) — the brief
//! rejects those at line 1815 of §5.6.

use std::time::{Duration, SystemTime, UNIX_EPOCH};

use thiserror::Error;

use crate::SqliteMemoryStore;

/// Lock acquisition mode.
#[derive(Debug, Clone, Copy)]
pub enum LockMode {
    /// Caller wants the only active hold on the resource.
    Exclusive,
}

/// Lock-table errors.
#[derive(Debug, Error)]
#[non_exhaustive]
pub enum LockError {
    /// Resource is already held by a non-expired holder.
    #[error("lock held: scope_kind={scope_kind} scope_key={scope_key}")]
    Held {
        /// Scope kind.
        scope_kind: String,
        /// Scope key.
        scope_key: String,
    },
    /// Underlying database error.
    #[error("lock db error")]
    Db(#[source] sqlx::Error),
    /// Clock failure.
    #[error("system clock pre-epoch")]
    Clock,
}

impl From<sqlx::Error> for LockError {
    fn from(e: sqlx::Error) -> Self { Self::Db(e) }
}

/// Handle that releases the lock when dropped (best effort; release is
/// idempotent and survives crash via TTL reclaim).
#[must_use = "drop the LockHandle to release; holding it idle keeps the lock"]
pub struct LockHandle {
    resource: String,
    holder_id: String,
    pool: sqlx::SqlitePool,
}

impl LockHandle {
    /// Explicit release. Idempotent.
    ///
    /// # Errors
    /// Returns `LockError::Db` on connection failure.
    pub async fn release(self) -> Result<(), LockError> {
        release_inner(&self.pool, &self.resource, &self.holder_id).await
    }
}

impl Drop for LockHandle {
    fn drop(&mut self) {
        // Best-effort fire-and-forget; expired-TTL reclaim is the safety net.
        let pool = self.pool.clone();
        let resource = std::mem::take(&mut self.resource);
        let holder = std::mem::take(&mut self.holder_id);
        tokio::spawn(async move {
            let _ = release_inner(&pool, &resource, &holder).await;
        });
    }
}

/// Acquire an EXCLUSIVE lock at (`scope_kind`, `scope_key`).
///
/// Returns `LockError::Held` if a non-expired holder exists for any caller.
/// Holders past `ttl` are reclaimed transparently.
///
/// # Errors
/// `LockError::Held` if contended; `LockError::Db` on connection failure;
/// `LockError::Clock` if the system clock is before UNIX epoch.
pub async fn acquire_exclusive(
    store: &SqliteMemoryStore,
    scope_kind: &str,
    scope_key: &str,
    holder_id: &str,
    ttl: Duration,
) -> Result<LockHandle, LockError> {
    let pool = store.pool().clone();
    let resource = format!("{scope_kind}:{scope_key}");
    let now = SystemTime::now()
        .duration_since(UNIX_EPOCH)
        .map_err(|_| LockError::Clock)?
        .as_millis()
        .min(i64::MAX as u128) as i64;
    let expires_at = now.saturating_add(i64::try_from(ttl.as_millis()).unwrap_or(i64::MAX));

    let mut tx = pool.begin().await?;

    // Reclaim: clear any holder whose expires_at <= now.
    sqlx::query("DELETE FROM lock_holders WHERE resource = ?1 AND expires_at <= ?2")
        .bind(&resource).bind(now)
        .execute(&mut *tx).await?;

    // Sync locks.holder_count after possible reclaim.
    sqlx::query(
        "UPDATE locks
            SET holder_count = (SELECT COUNT(*) FROM lock_holders WHERE resource = ?1),
                updated_at = ?2
          WHERE resource = ?1",
    )
    .bind(&resource).bind(now)
    .execute(&mut *tx).await?;

    // Insert the locks row if missing.
    sqlx::query(
        "INSERT INTO locks(resource, mode, holder_count, updated_at)
         VALUES (?1, 'exclusive', 0, ?2)
         ON CONFLICT(resource) DO NOTHING",
    )
    .bind(&resource).bind(now)
    .execute(&mut *tx).await?;

    // Probe: any non-expired holder?
    let count: i64 = sqlx::query_scalar(
        "SELECT COUNT(*) FROM lock_holders WHERE resource = ?1 AND expires_at > ?2",
    )
    .bind(&resource).bind(now)
    .fetch_one(&mut *tx).await?;

    if count > 0 {
        tx.rollback().await?;
        return Err(LockError::Held {
            scope_kind: scope_kind.to_owned(),
            scope_key: scope_key.to_owned(),
        });
    }

    sqlx::query(
        "INSERT INTO lock_holders(resource, holder_id, mode_requested, acquired_at, expires_at)
         VALUES (?1, ?2, 'exclusive', ?3, ?4)",
    )
    .bind(&resource).bind(holder_id).bind(now).bind(expires_at)
    .execute(&mut *tx).await?;

    sqlx::query(
        "UPDATE locks SET mode = 'exclusive', holder_count = 1, updated_at = ?2 WHERE resource = ?1",
    )
    .bind(&resource).bind(now)
    .execute(&mut *tx).await?;

    tx.commit().await?;

    Ok(LockHandle {
        resource,
        holder_id: holder_id.to_owned(),
        pool,
    })
}

async fn release_inner(
    pool: &sqlx::SqlitePool,
    resource: &str,
    holder_id: &str,
) -> Result<(), LockError> {
    let mut tx = pool.begin().await?;
    sqlx::query("DELETE FROM lock_holders WHERE resource = ?1 AND holder_id = ?2")
        .bind(resource).bind(holder_id)
        .execute(&mut *tx).await?;
    let now = SystemTime::now()
        .duration_since(UNIX_EPOCH).map_err(|_| LockError::Clock)?
        .as_millis().min(i64::MAX as u128) as i64;
    sqlx::query(
        "UPDATE locks
            SET holder_count = (SELECT COUNT(*) FROM lock_holders WHERE resource = ?1),
                updated_at = ?2
          WHERE resource = ?1",
    )
    .bind(resource).bind(now)
    .execute(&mut *tx).await?;
    tx.commit().await?;
    Ok(())
}
```

```rust
//! WAL helper for the `lint_repair` op kind (§5.6).

use thiserror::Error;
use uuid::Uuid;

use crate::SqliteMemoryStore;

/// Errors from lint-repair WAL transitions.
#[derive(Debug, Error)]
#[non_exhaustive]
pub enum LintRepairWalError {
    /// Underlying database error.
    #[error("wal db error")]
    Db(#[source] sqlx::Error),
    /// Illegal state transition (terminal-immutable trigger fired).
    #[error("illegal wal transition for op {0}")]
    IllegalTransition(String),
}

impl From<sqlx::Error> for LintRepairWalError {
    fn from(e: sqlx::Error) -> Self { Self::Db(e) }
}

/// Open a new lint-repair op in ISSUED.
///
/// # Errors
/// DB write failure.
pub async fn begin(store: &SqliteMemoryStore, actor: &str) -> Result<String, LintRepairWalError> {
    let op_id = Uuid::new_v4().to_string();
    sqlx::query(
        "INSERT INTO wal_ops(op_id, kind, state, actor, created_at)
         VALUES (?1, 'lint_repair', 'ISSUED', ?2, strftime('%s','now'))",
    )
    .bind(&op_id).bind(actor)
    .execute(store.pool()).await?;
    Ok(op_id)
}

/// Move ISSUED → PREPARED.
///
/// # Errors
/// Returns `IllegalTransition` if not in ISSUED.
pub async fn prepare(store: &SqliteMemoryStore, op_id: &str) -> Result<(), LintRepairWalError> {
    transition(store, op_id, "PREPARED").await
}

/// Move PREPARED → COMMITTED.
///
/// # Errors
/// Returns `IllegalTransition` if not in PREPARED.
pub async fn commit(store: &SqliteMemoryStore, op_id: &str) -> Result<(), LintRepairWalError> {
    transition(store, op_id, "COMMITTED").await
}

/// Move PREPARED → ABORTED with a reason. Idempotent for already-aborted.
///
/// # Errors
/// Returns `IllegalTransition` for invalid state.
pub async fn abort(
    store: &SqliteMemoryStore,
    op_id: &str,
    reason: &str,
) -> Result<(), LintRepairWalError> {
    let result = sqlx::query(
        "UPDATE wal_ops SET state = 'ABORTED', reason = ?2 WHERE op_id = ?1 AND state = 'PREPARED'",
    )
    .bind(op_id).bind(reason)
    .execute(store.pool()).await?;
    if result.rows_affected() == 0 {
        return Err(LintRepairWalError::IllegalTransition(op_id.to_owned()));
    }
    Ok(())
}

async fn transition(
    store: &SqliteMemoryStore,
    op_id: &str,
    target: &str,
) -> Result<(), LintRepairWalError> {
    let result = sqlx::query("UPDATE wal_ops SET state = ?2 WHERE op_id = ?1")
        .bind(op_id).bind(target)
        .execute(store.pool()).await?;
    if result.rows_affected() == 0 {
        return Err(LintRepairWalError::IllegalTransition(op_id.to_owned()));
    }
    Ok(())
}
```

```rust
use cairn_store_sqlite::locks::{LockError, acquire_exclusive};
use cairn_store_sqlite::wal::lint_repair as wal;

/// Wraps `fix_markdown_handler` in: lock-table acquire (lint_repair scope) +
/// WAL op (ISSUED→PREPARED→COMMITTED). On Held, surfaces `lint.fix_in_progress`.
///
/// # Errors
/// `LintFixError::FixInProgress` on contention; underlying handler errors otherwise.
pub async fn fix_markdown_with_lock(
    store: &SqliteMemoryStore,
    vault_root: &Path,
    ttl: Duration,
) -> Result<FixMarkdownResult, LintFixError> {
    let vault_id = vault_id(vault_root); // hash(canonical path); pure helper
    let holder_id = format!("pid={} t={}", std::process::id(), uuid::Uuid::new_v4());

    let lock = match acquire_exclusive(
        store, "lint_repair", &vault_id, &holder_id, ttl,
    ).await {
        Ok(h) => h,
        Err(LockError::Held { .. }) => return Err(LintFixError::FixInProgress),
        Err(e) => return Err(LintFixError::Lock(e)),
    };

    let op_id = wal::begin(store, &holder_id).await.map_err(LintFixError::Wal)?;
    wal::prepare(store, &op_id).await.map_err(LintFixError::Wal)?;

    let result = match fix_markdown_handler(store, vault_root).await {
        Ok(r) => {
            wal::commit(store, &op_id).await.map_err(LintFixError::Wal)?;
            Ok(r)
        }
        Err(e) => {
            let _ = wal::abort(store, &op_id, "fix_markdown_handler error").await;
            Err(LintFixError::Handler(e))
        }
    };
    drop(lock);
    result
}

    #[error("handler error")]
    Handler(#[source] anyhow::Error),
}
```

```rust
    };
}
```

Crash recovery cannot literally SIGKILL within a single process easily — but the lock-table TTL reclaim path can be exercised by acquiring with a short TTL and then sleeping past it.

```rust
#[tokio::test]
async fn killed_fix_run_unblocks_after_ttl() {
    use std::time::Duration;
    use cairn_store_sqlite::locks::acquire_exclusive;
    let store = cairn_store_sqlite::open_in_memory().await.unwrap();

    // "Crashed" holder: acquire and forget the handle, with a tiny TTL.
    let h = acquire_exclusive(&store, "lint_repair", "v", "crashed", Duration::from_millis(50))
        .await.unwrap();
    std::mem::forget(h);

    tokio::time::sleep(Duration::from_millis(120)).await;

    // Next run reclaims.
    let _h2 = acquire_exclusive(&store, "lint_repair", "v", "next", Duration::from_secs(60))
        .await.expect("reclaim after TTL expiry");
}
```
