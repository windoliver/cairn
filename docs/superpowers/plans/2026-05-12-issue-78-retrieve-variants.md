# Issue 78 Retrieve Variants Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement full session, turn, and tool-call retrieve variants for issue #78 in one PR.

**Architecture:** Add `tool_call` to the canonical IDL, regenerate all generated surfaces, then implement runtime behavior in the CLI retrieve handler with pure response-shaping helpers in `cairn-core`. Session retrieval becomes turn-windowed with deterministic cursors and budget trimming; turn and tool-call retrieval share the existing scoped list path and expose linkage metadata without reading raw payload refs.

**Tech Stack:** Rust workspace, JSON Schema IDL, `cairn-codegen`, Clap, generated serde types, SQLite-backed `MemoryStore`, cargo tests.

fn trace_linkage(record: &MemoryRecord) -> Option<TraceLinkage> {
    let trace = record
        .extra_frontmatter
        .get("trace")
        .and_then(serde_json::Value::as_object);
    let trace_event = trace_event(record);
    if trace.is_none() && trace_event.is_none() {
        return None;
    }
    let trace = trace?;
    Some(TraceLinkage {
        capture_event_id: trace_string(trace, "capture_event_id"),
        parent_event_id: trace_string(trace, "parent_event_id"),
        payload_hash: trace_string(trace, "payload_hash"),
        record_id: wire_ulid(record.id.as_str()),
        sequence: trace.get("sequence").and_then(serde_json::Value::as_i64),
        tool_call_id: trace_string(trace, "tool_call_id"),
        trace_event,
    })
}

fn trace_string(
    trace: &serde_json::Map<String, serde_json::Value>,

    trace

}

fn parse_session_cursor(
    cursor: Option<&cairn_core::generated::common::Cursor>,
    order: RetrieveArgsSessionOrder,
) -> Result<usize, Response> {
    let Some(cursor) = cursor else {
        return Ok(0);
    };
    let expected_order = match order {
        RetrieveArgsSessionOrder::Asc => "asc",
        RetrieveArgsSessionOrder::Desc => "desc",
        _ => "asc",
    };
    let parts = cursor.0.split(':').collect::<Vec<_>>();
    if parts.len() != 4 || parts[0] != "session" || parts[1] != "v1" || parts[2] != expected_order {
        return Err(invalid_args_response(
            ResponseVerb::Retrieve,
            "cursor",
            "invalid session cursor for requested order",
        ));
    }
    parts[3].parse::<usize>().map_err(|_| {
        invalid_args_response(
            ResponseVerb::Retrieve,
            "cursor",
            "invalid session cursor offset",
        )
    })
}
